# sabarepo
日本語のREADMEはこちらです: [README.ja.md](README.ja.md)

「Sabarepo」プロジェクトのためのウェブベースのビューアーで、ユーザーが福井県鯖江市の様々な場所や出来事についての情報を閲覧・表示できるようになっています。

## デモ
このプロジェクトは[https://codeforfukui.github.io/sabarepo/](https://codeforfukui.github.io/sabarepo/)でホストされています。

## 機能
- 様々な場所やイベントのマーカーを表示するマップを表示します
- タイプ別(例: "鯖江の景色"、"興味深い"、"危険スポット")でフィルタリングできます
- タイトル、タイプ、タイムスタンプ、関連画像など、各アイテムの詳細情報を提供します
- マップマーカーやリストアイテムをクリックして、より詳細な情報を表示できます

## 要件
このプロジェクトには、JavaScript が有効な最新の Web ブラウザが必要です。

## 使用方法
Sabarepoビューアを使うには、単に[プロジェクトのウェブサイト](https://codeforfukui.github.io/sabarepo/)をWebブラウザで開くだけです。利用可能な場所やイベントを閲覧でき、種類別にフィルタリングすることができ、アイテムをクリックすると詳細を表示できます。

## データ / API
Sabarepo ビューワーは[Sabarepo API](https://api.odp.jig.jp/sabarepo/poslog/index.json)からデータを取得しています。このAPIは佐賀市エリアにある様々な場所や催し物に関する情報を提供しています。
